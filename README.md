# CAD-design-Project
A collection of CAD projects demonstrating proficiency in 2D technical drafting to professional engineering standards and 3D solid modeling of fluid mechanics apparatus (Venturi meter).
This repository contains a portfolio of CAD projects focused on technical drafting, spatial reasoning, and 3D modelling. The tasks demonstrate an ability to translate design constraints into precise 2D engineering layouts and complex 3D models.

Key Projects

Orthographic Drafting & Cross-Sectioning (2D): Produced a fully dimensioned, 1st angle orthographic projection of an embossed component. The drawing package includes detailed front and plan views, along with a precision sectioned end-view utilizing cutting planes and hatching. The final deliverable was formatted to professional engineering standards on an A3 layout, complete with accurate center lines and hidden detail representations.

Venturi Meter Parametric Modelling (3D): Developed a comprehensive 3D solid model of a 5-section Venturi meter based on strict proportional constraints and geometric relationships. The model accurately features converging and diverging pipe sections (maintaining a uniform 2cm thickness) and includes precisely positioned 2mm instrumentation ports for pressure measurement in the main pipe and throat.
